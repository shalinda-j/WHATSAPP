## Data Flow Architecture

```
User Sends Message → WhatsApp API → Baileys → Message Handler → Service Routing
       ↓                 ↓              ↓            ↓              ↓
   Text/Voice      Message       Processed    Intent/Type    Appropriate
   Message        Received      Message      Identified     Service
       ↓                 ↓              ↓            ↓              ↓
┌─────────────────────────────────────────────────────────────────────────┐
│                         PROCESSING PIPELINE                           │
│  ┌─────────────────┐  ┌─────────────────┐  ┌─────────────────┐      │
│  │   Preprocessing │  │   Intelligence  │  │   Response      │      │
│  │   (Clean,      │  │   (AI, NLP,    │  │   Generation    │      │
│  │   Validate)     │  │   Voice)        │  │   (Format,     │      │
│  └─────────────────┘  └─────────────────┘  │   Delivery)     │      │
```
