## 2025-05-14 - Path Traversal Vulnerability in File Deletion
**Vulnerability:** A critical path traversal vulnerability was found in the CV deletion route (`DELETE /registrations/:id/cv`). The `cvUrl` parameter, which may be manipulated by users via mass-assignment, was directly appended to the base directory path via `path.join`, enabling arbitrary file deletion if an attacker passed strings containing `../../`.
**Learning:** File paths must be strictly checked and anchored to the expected base directory using `path.resolve` and `startsWith(baseDir + path.sep)`, before any destructive file operations (like `fs.unlinkSync`). `path.join` is insufficient alone for security as it evaluates relative path combinations.
**Prevention:** Always construct file paths securely and restrict resolving outside intended scopes when relying on potentially unsafe data (e.g. `cvUrl`).
