## 2024-07-01 - Prevent Mass Assignment on Webhook Endpoint
**Vulnerability:** The `/api/webhooks` POST and PUT endpoints directly spread `req.body` into `new Webhook({...req.body})` and `findOneAndUpdate(..., req.body, ...)` respectively. This Mass Assignment (CWE-915) allowed attackers to bypass standard input validation and potentially override sensitive properties (e.g. `tenantId`).
**Learning:** Whenever an API route directly merges or spreads a request object into a database model operation, it is vulnerable to Mass Assignment, unless explicitly restricted by the database schema (which is rarely foolproof for meta-properties).
**Prevention:** Always extract only the required, safe properties from `req.body` (e.g., using object destructuring: `const { name, url } = req.body`) and build a targeted `updateData` object to pass into the database query (via `$set` in Mongoose).
